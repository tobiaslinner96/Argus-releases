# Argus

Mirror parts of the Tibia window into separate always-on-top windows, and copy
Tibia's screenshots straight to the clipboard.

**[Download the latest version](https://github.com/tobiaslinner96/Argus-releases/releases/latest)** – run `ArgusSetup-<version>.exe`.

Once installed, Argus checks for new versions when it starts and offers to update itself.

Windows may warn that the file is unrecognized because it isn't code-signed yet: click
*More info → Run anyway*.
